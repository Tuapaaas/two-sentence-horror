A two-sentence horror story for make.fun's "Two-Sentence Horror" bounty: an ordinary first sentence — a baby monitor playing lullabies nobody switched on — and a second sentence that reframes it. The thing in the nursery has finally learned the words.

## Run it

```sh
node main.ts
```

This writes the story (exactly two sentences, 177 characters) to `output/entry.txt`, or to `$MAKEFUN_OUTPUT_DIR/entry.txt` when set.
